# Windows 桌面字幕应用 0.4.6

解压完整文件夹，双击 `Subtitle Studio.exe`。无需安装 Python 或打开浏览器。升级时先关闭已打开的旧版窗口，再重新打开最新版；启动时保留 0.4.5 的配置恢复，不需要重新填写 API 密钥。已有实例未退出时，单实例机制会继续显示旧版窗口。本机已添加桌面快捷方式 `Subtitle Studio`，与源码工作目录的 `启动桌面字幕.cmd` 共用稳定启动脚本，按版本号优先选择已构建的最新桌面应用，并隐藏启动终端；已有有效配置不会被替换。悬停应用名称可查看当前版本。

- 界面采用雾白半透明背景（`rgba(248, 250, 253, alpha)`）与深灰、正常字重字幕，控件使用轻边框和淡蓝状态。
- 拖动窗口顶部移动位置；拖动四边或四角调整窗口大小，最小为 420 × 240。
- 点击「CAP」进入浮动字幕；点击「UI」返回完整界面，选择音频来源和语言。
- 「ST」开始翻译，「SP」停止并保存录音；字幕模式中也可使用，切换视图不会重新建立翻译会话。
- 字幕模式左上角的声波图标显示当前连接与翻译状态：正在连接为蓝色；本机服务及字幕连接正常，且处于监听、识别或翻译时为绿色并缓慢跳动；停止时保持静止、颜色淡化；出错或连接中断时为红色。悬停可查看说明，系统开启减少动画时只变化颜色。
- 完整界面和字幕模式均可点击「SET」按需展开或收起显示设置，分别调整原文和译文字号，范围为 10–160 px，可拖动滑块或输入数字。
- SET 中原文显示（`SRC`）与译文显示（`TR`）为独立图标开关，默认都开启。可仅显示原文、仅显示译文、显示两者或全部隐藏，选择立即作用于已有与后续字幕，不清空字幕记录、不重启翻译会话；完整关闭并重开后恢复选择。「RST」只恢复字号和颜色，不改变这两个开关。
- 原文、译文可分别选择字体颜色：点击各自色块打开颜色选择器，或在旁边输入 `#RRGGBB` 格式的 HEX 色值。颜色即时应用到已有字幕及后续字幕；默认原文为 `#68788C`、译文为 `#283445`。「RST」恢复默认字号和颜色。
- 背景不透明度可调为 15%–100%，初始为 72%；数值越低，越容易看到下面的会议或视频。文字保持不透明。
- 字幕历史隐藏可见滚动条，仍可使用滚轮浏览；聚焦字幕区域后可使用 PageUp 向上翻页、End 回到末尾。
- 「PIN」切换置顶，淡蓝背景和按下状态表示窗口始终显示在其他普通窗口上方，再点击可取消。
- 窗口位置、大小、置顶状态、原文 / 译文显示选择、字号、字体颜色、背景不透明度会在下次打开时恢复。显示设置保存在 `%APPDATA%\Subtitle Studio\display.json`，不受每次启动随机服务端口的影响；两个显示开关对应 `showSourceText` / `showTranslationText`，默认均为 true。

## 云翻译配置

0.4.5 修复 Windows MSIX 目录重定向造成的配置路径差异。文件标识核对确认，普通 Windows 启动读取的 Roaming 主 `.env` 中密钥与区域为空；此前从 Codex 中读取到的有效配置，实际位于 Codex MSIX 的 `LocalCache\Roaming` 影子目录。这是同一台电脑上的不同实际文件，已保存密钥仍在影子目录中，并非需要每次重开重新填写。

新版启动时，只有默认主配置不完整、且现有部分设置与保存值兼容，才从指定的已知 Codex MSIX `Subtitle Studio\.env` 保存位置恢复。已有完整主配置或部分设置冲突时不会覆盖；恢复保留注释、无关设置和已有短语表。恢复只在本机进行，便携包不包含密钥。关闭旧版并重开最新版后使用恢复后的配置；无需重新输入 API 密钥。

0.4.4 修复启动时云配置尚未读取完成、或首次读取失败时误报 `Cloud not configured` 的问题。点击播放会等待尚未完成的读取，或重新检查配置；读取失败会提示重试。如果本机配置存在，但后台服务未加载，会提示重新启动应用，无需重新填写密钥。只有确认本机缺少配置时，才打开首次配置表单。等待、读取失败或缺配置时均保留字幕历史，不启动字幕会话。

`Server: Online` 只表示本机服务可连接，云翻译准备状态须等待配置检查。CFG 中密钥输入框为空是保护密钥的正常设计，不能据此判断密钥丢失。此前对保存配置的只读检查和既有识别日志均来自 Codex 影子目录，不能证明普通 Windows 启动读到了该配置；没有复制日志中的字幕内容。

0.4.2 已修复启动进程继承的旧值或空白值覆盖本机 `.env` 的问题，后续版本保留该修复。

桌面启动时，以本机选定 `.env` 中的 Speech key / region / phrase 三项作为后端工作进程的环境值，覆盖启动进程继承的旧值或空白值；同时传入 `SUBTITLE_STUDIO_ENV_FILE` 和 `SUBTITLE_STUDIO_DATA_DIR`。CFG 与后端使用一致的配置解析，支持 UTF-8 BOM 和带引号的值。0.4.5 只在满足恢复条件时补全默认主配置，保留影子目录中的原保存文件；便携包仍不包含密钥。

功能按键尽可能使用细线图标，悬停显示中文功能及英文缩写；本文继续用缩写说明对应操作。图标对应：播放 = 开始（`ST`）、方块 = 停止（`SP`）、字幕窗 = 字幕模式（`CAP`）、布局 = 完整界面（`UI`）、调节 = 显示设置（`SET`）、图钉 = 置顶（`PIN`）、钥匙 = 云服务配置（`CFG`）、文件夹 = 录音与日志（`LOG`）、保存 = 保存并重启（`SAV`）、刷新 = 重置字号和颜色（`RST`）或检查连接（`CHK`）。

SET 中两个显示开关分别标识原文（`SRC`）和译文（`TR`），按下状态表示显示，取消表示隐藏；切换只影响显示内容，隐藏后的字幕记录仍保留。

应用名称旁的声波是状态指示图标，无需点击：蓝色表示连接中，绿色跳动表示连接正常并正在处理字幕，淡色静止表示停止，红色表示错误。绿色表示会话及连接处于活动状态，真实音频与识别结果仍需结合当前字幕判断。

便携包不包含任何密钥。确认本机缺少配置时，在「SET → CFG」首次输入自己的 Azure Speech 区域和密钥，然后点击「SAV」保存并重新启动。已经配置过的密钥不会显示在界面上；密钥框留空表示保留现有密钥，不需要每次升级重新输入。

各桌面版本默认使用当前 Windows 用户的 `%APPDATA%\Subtitle Studio`，配置、录音、用量记录及日志仅保存在本机，点击「LOG」可打开。MSIX 环境可能把同一逻辑路径重定向到应用自己的影子目录；0.4.5 针对已知 Codex 保存配置恢复普通 Windows 启动所需的主配置。更换便携包不会清除原配置或颜色设置。关闭应用会停止由它启动的服务，不会停止其他已运行的网页或远程测试服务。

便携包只附带 Cloud 实时翻译所需组件，不附带 Whisper、FunASR 或其他离线模型。Cloud 需要网络和有效云服务配置。窗口背景透明不会自动隔离 Teams 音频，System 仍使用现有 Windows 系统音频捕获方式。

## 从源码构建

1. 使用已有 Python 3.11 环境和项目的轻量云端依赖。
2. 下载 Electron 44.5.1 Windows x64 官方压缩包到 `.cache/desktop-build/downloads/`。下载前选择 VPS/代理或直连；默认使用 Motrix，按官方 SHA256 校验。
3. 在 `.venv` 中安装 PyInstaller，建议通过同一选定路线下载 wheel 并离线安装。
4. 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1`。
5. 输出包含完整便携目录和 ZIP。不要单独移动 EXE；它需要同目录的运行组件。

桌面窗口使用透明、无边框的 Electron 窗口；原生自动缩放在某些平台会影响透明效果，因此八个方向的拖拽通过窗口坐标调整尺寸。页面没有 Node.js 权限，桌面接口仅开放固定的窗口操作和本机云服务设置。
