# 技术交接

基线：桌面 **0.4.6**，2026-10-03。本文件仅记录可公开的实现规则和验证边界。

API 反复要求配置的根因是 Windows MSIX 文件重定向：Codex 启动环境与普通 Windows 启动可能将同一逻辑 Roaming 路径映射到不同实际文件，前者保存的配置仍在应用影子目录，而普通启动主配置为空。不能凭逻辑路径相同或 Codex 内启动成功，认定普通桌面已读取同一文件。

`recoverSavedCloudConfig` 只恢复固定的 Speech key / region / phrase；完整主配置直接返回，主配置部分值与候选值冲突时拒绝恢复。保留源配置、注释、无关行和已有短语；使用同目录临时文件替换，重复恢复不改写完整配置。正式默认路径才恢复，显式路径及隔离验收不恢复。工作进程使用同一配置解析结果覆盖继承环境的三项值，CFG 从不回显密钥。

显示设置跨服务随机端口保存到原生 `display.json`。`showSourceText` / `showTranslationText` 仅接受布尔值，默认均显示；隐藏保留节点和历史，不改变翻译会话。RST 保留显示选择。`window.json` 保存窗口状态，两类设置与便携目录分离。

0.4.6 的 37 / 39 项原生检查使用隔离配置、合成字幕和受控连接；30 项单元测试覆盖配置、实际启动恢复函数、窗口几何及配置预检。它们不能证明真实音频或付费识别成功。MSIX 修复另以实际主文件迁移、源配置未变、重复迁移不改写及两个独立冻结后端读取同一文件为证据；Codex 发起窗口仍可能被重定向，不能替代普通 Explorer 界面验收。

交接只同步源码和公开说明，不同步私有 `.env`、录音、模型、日志、诊断结果、运行缓存或便携构建产物。具体验收见 [QA 清单](QA_CHECKLIST.md)，构建及操作见 [桌面说明](DESKTOP_APP.md)。
