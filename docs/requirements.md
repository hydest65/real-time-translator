# 当前需求入口

基线：Windows 桌面应用 **0.4.6**，2026-10-03。当前支持实时 Cloud 字幕、字幕历史、本机录音和独立显示设置；Notes / Word 纪要生成不属于当前应用范围。

- 完整便携目录解压后直接运行，无需安装 Python；桌面快捷方式及源码启动入口选择已构建的最高版本。
- 淡色半透明背景、图标操作、置顶、八向调整窗口大小，最小 420 × 240。
- 原文和译文分别支持 10–160 px 字号、字体颜色及 SRC / TR 显示开关；背景不透明度为 15%–100%。选择自动保存，重启恢复，隐藏不清空字幕或重启会话。
- 字幕模式声波图标区分连接、正常活动、停止和错误；减少动画时静止。
- 已保存 API 配置持续复用，默认主配置缺失且兼容时恢复指定 MSIX 保存配置；有效配置及冲突部分值不覆盖。
- 私有配置、录音、模型、日志和构建缓存仅留本机，不进入 GitHub 源码或便携包。

使用细节见 [桌面说明](DESKTOP_APP.md)，完整需求与旧版背景见 [产品需求](PRODUCT_REQUIREMENTS.md)，当前验收和限制见 [QA 清单](QA_CHECKLIST.md)。
